# Data Dictionary and Source Citations

All files in this folder are generated by `scripts/build_demo_data.py`. Every dataset has a **status**:

| Status | Meaning |
| --- | --- |
| **Approximate public (verify)** | Values transcribed from a public source. They are approximate and must be checked against the original before being cited. |
| **Public-derived** | Classification or naming taken from a public standard (e.g., SOC codes, OMB metro names). |
| **Demo estimate** | Illustrative values derived from public figures with the documented rules in the build script. These are **not** official statistics. |
| **Demo (curated)** | Editorial judgments made for this project (e.g., skill importance). |
| **Synthetic demo** | Randomly generated records. They do **not** represent real people or ChiEAC data. |

`dataset_catalog.csv` repeats this information in machine-readable form, and the app shows it under every chart.

## `skills.csv`: skills taxonomy (Demo, curated)
| Column | Type | Description |
| --- | --- | --- |
| `skill` | text | Canonical skill name used across the app |
| `skill_category` | text | One of 8 skill areas (Programming, Data & Databases, AI & Machine Learning, Analytics & BI, Cloud & DevOps, Security & Networking, Web & Software Engineering, Business & Professional) |
| `description` | text | Short plain-language description |

Informed by the O*NET Technology Skills vocabulary: <https://www.onetcenter.org/database.html>.

## `occupations.csv`: career paths and SOC crosswalk (Public-derived)
| Column | Type | Description |
| --- | --- | --- |
| `occupation_id` | text | Stable ID used throughout the app |
| `occupation` | text | Career path name shown to users |
| `category` | text | Career area used for filtering |
| `soc_code` | text | BLS 2018 Standard Occupational Classification code used for wage and employment data |
| `soc_title` | text | Official SOC title |
| `soc_is_proxy` | yes/no | `yes` when BLS has no standalone code for the title and the closest SOC is used |
| `location_group` | text | Grouping used by the demo metro multipliers (data, software, infra, business) |
| `typical_entry_education` | text | BLS typical entry-level education |
| `description` | text | Short role description |

Source: BLS SOC 2018, <https://www.bls.gov/soc/2018/>.

## `occupation_skills.csv`: skill importance by career path (Demo, curated)
| Column | Type | Description |
| --- | --- | --- |
| `occupation_id` | text | FK to `occupations.csv` |
| `skill` | text | FK to `skills.csv` |
| `importance` | int 1–5 | 5 = core, 4 = very important, 3 = important, 2 = helpful, 1 = nice to have |

Ratings are editorial judgments informed by O*NET OnLine (<https://www.onetonline.org/>) and common job-posting
requirements. They are **not** O*NET importance scores.

## `bls_national_occupations.csv`: national employment, wages and projections (Approximate public, verify)
| Column | Type | Description |
| --- | --- | --- |
| `soc_code`, `soc_title` | text | SOC identifier and title |
| `employment` | int | National employment, OEWS May 2023 |
| `wage_p10`, `wage_median`, `wage_p90` | int (USD/yr) | 10th percentile, median and 90th percentile annual wage, OEWS May 2023 |
| `projected_growth_pct_2023_2033` | int (%) | Projected employment change 2023–2033, BLS Employment Projections. Where BLS publishes a combined projection (e.g., software developers and QA testers), the combined figure is used. |
| `typical_entry_education` | text | BLS typical entry-level education |
| `reference_period`, `data_status` | text | Provenance labels |

Sources: BLS OEWS (<https://www.bls.gov/oes/tables.htm>) and BLS Employment Projections
(<https://www.bls.gov/emp/tables/occupational-projections-and-characteristics.htm>). Reference period May 2023 /
2023–2033. Values are approximate transcriptions. Verify them before citing.

## `locations.csv`: metro areas (Public-derived)
| Column | Type | Description |
| --- | --- | --- |
| `location_id` | text | Stable ID |
| `location_name` | text | OMB Metropolitan Statistical Area name (or "United States (national)") |
| `short_name` | text | Short label for charts |
| `area_type` | text | National or Metropolitan Statistical Area |
| `state` | text | Primary state |
| `lat`, `lon` | float | Approximate city-center coordinates for the map |

## `wages_by_location.csv`: employment and wages by location (Demo estimate; national row approximates BLS)
| Column | Type | Description |
| --- | --- | --- |
| `soc_code`, `location_id` | text | Keys |
| `employment` | int | Estimated employment |
| `wage_p10` … `wage_p90` | int (USD/yr) | Wage percentiles (10th, 25th, median, 75th, 90th) |
| `location_quotient` | float | Concentration relative to the U.S. (1.0 = national average) |
| `reference_period`, `data_status` | text | Provenance labels |

Derivation for metro rows: `employment = national_employment × metro_share_of_US_jobs × location_quotient`, and
`wage = national_wage × metro_wage_factor × group_wage_tilt`. The 25th and 75th percentiles are interpolated at every
location (`p25 = median − 0.45 × (median − p10)`, `p75 = median + 0.45 × (p90 − median)`). Official metro estimates
are available at <https://www.bls.gov/oes/current/oessrcma.htm>.

## `industry_distribution.csv`: industry mix by occupation (Demo estimate)
| Column | Type | Description |
| --- | --- | --- |
| `soc_code` | text | Key |
| `industry` | text | NAICS-based sector label |
| `share_pct` | int (%) | Illustrative share of national employment in that sector (sums to 100 per SOC) |
| `data_status` | text | Provenance label |

Modelled on the structure of BLS OEWS industry-specific estimates and Data USA occupation profiles
(<https://datausa.io/>).

## `demo_profiles.csv`: synthetic student profiles (Synthetic demo)
| Column | Type | Description |
| --- | --- | --- |
| `record_id` | text | Random sequential ID (`DEMO-0001`…). It is not linked to any person. |
| `cohort_quarter` | text | Quarter the profile was created (e.g., 2026-Q1) |
| `location_id` | text | FK to `locations.csv` |
| `education_level` | text | Coarse education band |
| `field_of_study` | text | Coarse field band |
| `target_occupation_id` | text | FK to `occupations.csv` |
| `skills` | text | Semicolon-separated skills |
| `is_synthetic` | yes/no | Always `yes` in this repository |

Generated with random seed 42. The file intentionally contains **no** names, emails, dates of birth, nationality,
visa status or free text.

## `dataset_catalog.csv`: dataset registry
One row per dataset with `title`, `file`, `publisher`, `source_url`, `reference_period`, `compiled_on`,
`data_status` and `notes`. The app reads this file to print citations under charts.

---

### Refreshing with official data
1. Download the national and metropolitan OEWS tables from <https://www.bls.gov/oes/tables.htm>.
2. Replace the values in `BLS_NATIONAL`, or write the downloaded metro rows straight into `wages_by_location.csv` with
   the same columns and set `data_status` to `Public (BLS OEWS)`.
3. Update `reference_period` and `compiled_on` in `dataset_catalog.csv`.
4. Run `pytest` to confirm the schema checks still pass.
